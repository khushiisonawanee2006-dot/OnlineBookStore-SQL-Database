# 📚 Bookstore SQL Database Project

## Overview
This project is a Bookstore Database Management System developed using MySQL. It demonstrates database creation, data import, relationships, and SQL queries for analyzing bookstore data.

## Features
- Database creation
- Books, Customers, and Orders tables
- Primary Key & Foreign Key relationships
- CSV data import
- CRUD Operations
- Joins
- Aggregate Functions
- Subqueries
- GROUP BY, HAVING, ORDER BY
- Business Analysis Queries

## Technologies Used
- MySQL
- MySQL Workbench

## SQL Concepts Covered
- DDL
- DML
- Constraints
- Joins
- Aggregate Functions
- Subqueries
- GROUP BY
- HAVING
- ORDER BY
- Window Functions (if added)

## Project Structure
- Database Schema
- SQL Scripts
- CSV Files
- Query Solutions

## Sample Queries
- Find the most expensive book
- Retrieve books by genre
- Calculate total revenue
- Find top customers
- Total books sold by each author
- Remaining stock after orders
